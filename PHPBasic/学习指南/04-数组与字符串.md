# 04｜数组与字符串

## 学习目标

能使用索引数组、关联数组、遍历、常用数组函数和字符串处理函数完成基础数据处理。

## 1. 索引数组与关联数组

```php
<?php
$languages = ['PHP', 'C', 'Python'];

$user = [
    'name' => 'Kai',
    'role' => 'developer',
    'active' => true,
];

echo $languages[0], PHP_EOL;
echo $user['name'], PHP_EOL;
```

PHP 的数组同时支持列表和键值映射。访问不存在的键可能产生警告，因此读取不确定的数据时，应先使用 `isset()`、`array_key_exists()` 或空合并运算符判断。

## 2. 遍历与转换

```php
<?php
$prices = ['book' => 35, 'pen' => 5, 'bag' => 120];

foreach ($prices as $product => $price) {
    printf("%s: %.2f\n", $product, $price);
}

$values = array_values($prices);
$keys = array_keys($prices);
```

`isset($array['key'])` 在键不存在或对应值为 `null` 时返回 `false`；`array_key_exists('key', $array)` 只判断键是否存在。

## 3. 常见数组函数

```php
<?php
$numbers = [8, 3, 5, 3, 10];

$unique = array_values(array_unique($numbers));
sort($unique);

$sum = array_sum($unique);
$count = count($unique);

echo '数量：', $count, PHP_EOL;
echo '总和：', $sum, PHP_EOL;
print_r($unique);
```

注意：`sort()` 会直接修改数组，并重新建立数字索引；若要保留键值关系，应根据需求选择 `asort()` 或 `ksort()`。

## 4. 字符串处理

```php
<?php
$title = '  Learn PHP  ';

$clean = trim($title);
echo strtoupper($clean), PHP_EOL;
echo strlen($clean), PHP_EOL;
echo str_contains($clean, 'PHP') ? '包含 PHP' : '不包含 PHP';
```

`str_contains()` 需要 PHP 8.0 或更高版本。对于 UTF-8 中文字符串，`strlen()` 统计的是字节数，不一定是字符数；需要字符语义时可使用相应的多字节字符串函数，并确保启用了 mbstring 扩展。

## 5. 安全地输出 HTML

```php
<?php
$userInput = '<script>alert("x")</script>';

echo htmlspecialchars(
    $userInput,
    ENT_QUOTES | ENT_SUBSTITUTE,
    'UTF-8'
);
```

将普通文本插入 HTML 时应进行上下文正确的编码。不要把 HTML 转义与输入校验混为一谈：前者保护输出上下文，后者验证数据是否符合业务规则。

## 练习

1. 创建一个关联数组保存书名、作者、评分。
2. 计算一组成绩的平均值、最大值和最小值。
3. 对字符串去除首尾空白，并判断是否包含指定关键字。
4. 对中文文本测试 `strlen()` 与 `mb_strlen()` 的差异。
5. 将用户输入安全地显示到 HTML 页面中。

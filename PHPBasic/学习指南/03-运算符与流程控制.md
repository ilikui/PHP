# 03｜运算符与流程控制

## 学习目标

掌握表达式、比较、逻辑运算、条件分支与循环，并能清楚处理边界情况。

## 1. 运算符

```php
<?php
$price = 120;
$quantity = 3;
$total = $price * $quantity;

$isMember = true;
$hasCoupon = false;
$canDiscount = $isMember || $hasCoupon;

echo $total, PHP_EOL;
var_dump($canDiscount);
```

常见运算符包括算术、赋值、比较、逻辑、字符串连接和空合并运算符。PHP 字符串连接使用点号 `.`，不是加号。

## 2. 条件分支

```php
<?php
$score = 86;

if ($score < 0 || $score > 100) {
    echo '成绩超出范围';
} elseif ($score >= 90) {
    echo '优秀';
} elseif ($score >= 80) {
    echo '良好';
} elseif ($score >= 60) {
    echo '及格';
} else {
    echo '需要继续努力';
}
```

先校验合法范围，再进行业务分支，可以避免把非法输入误判为正常结果。

PHP 8.0 起可以使用 `match` 表达式做严格匹配：

```php
<?php
$status = 200;

$message = match ($status) {
    200 => '成功',
    400, 422 => '请求有误',
    401, 403 => '无权访问',
    404 => '资源不存在',
    default => '其他状态',
};

echo $message;
```

`match` 使用严格比较，且每个分支需要产生结果；使用前确认项目 PHP 版本至少为 8.0。

## 3. 循环

```php
<?php
$sum = 0;

for ($i = 1; $i <= 100; $i++) {
    $sum += $i;
}

echo $sum; // 5050
```

```php
<?php
$users = ['小林', '小周', '小陈'];

foreach ($users as $index => $user) {
    echo ($index + 1), '. ', $user, PHP_EOL;
}
```

- `for` 适合有明确计数过程的循环。
- `while` 在条件为真时继续执行。
- `foreach` 适合遍历数组和可迭代对象。
- `break` 结束循环；`continue` 跳过当前迭代剩余语句。

## 4. 空合并与三元表达式

```php
<?php
$displayName = $_GET['name'] ?? '访客';
$isAdult = $age >= 18 ? true : false;
```

空合并运算符 `??` 在左侧变量不存在或为 `null` 时使用右侧默认值。它不会替代对输入类型和内容的验证。Web 场景下，输出到 HTML 前仍需进行正确转义。

## 练习

1. 输入一个整数，判断正负、奇偶。
2. 编写成绩等级判断，并处理不在 0～100 范围内的情况。
3. 使用循环计算 1～100 的和、偶数和。
4. 遍历一个关联数组，格式化输出键和值。
5. 使用 `match` 将 HTTP 状态码转换为提示文本。

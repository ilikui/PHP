# 05｜函数与代码复用

## 学习目标

理解函数参数、返回值、类型声明、作用域和异常处理，学会把重复逻辑提取为可测试的函数。

## 1. 定义函数

```php
<?php
declare(strict_types=1);

function calculateAverage(array $scores): float
{
    if ($scores === []) {
        throw new InvalidArgumentException('成绩列表不能为空');
    }

    foreach ($scores as $score) {
        if (!is_int($score) && !is_float($score)) {
            throw new InvalidArgumentException('成绩必须是数字');
        }
        if ($score < 0 || $score > 100) {
            throw new InvalidArgumentException('成绩必须在 0 到 100 之间');
        }
    }

    return array_sum($scores) / count($scores);
}

echo calculateAverage([80, 90, 100]);
```

好的函数应有明确的输入、输出和失败方式。返回类型能帮助调用者理解结果，但复杂业务规则仍需要显式验证。

## 2. 默认参数与命名参数

```php
<?php
function greet(string $name, string $prefix = '你好'): string
{
    return $prefix . '，' . $name;
}

echo greet('小林');
echo greet(name: '小周', prefix: '欢迎');
```

命名参数自 PHP 8.0 起可用。公共函数应谨慎调整参数名称，因为调用方可能使用命名参数。

## 3. 作用域与副作用

```php
<?php
$taxRate = 0.1;

function calculateTax(float $amount, float $rate): float
{
    return $amount * $rate;
}

echo calculateTax(100, $taxRate);
```

显式传参比依赖全局变量更容易测试。函数如果能仅依靠参数计算结果，通常更容易理解、复用和验证。

## 4. 异常处理

```php
<?php
function divide(float $a, float $b): float
{
    if ($b == 0.0) {
        throw new InvalidArgumentException('除数不能为零');
    }

    return $a / $b;
}

try {
    echo divide(10, 2);
} catch (InvalidArgumentException $exception) {
    echo '输入错误：', $exception->getMessage();
}
```

异常应在合适的边界处理。不要用空的 `catch` 把错误静默吞掉；面向用户的系统也不应把内部堆栈直接返回给用户。

## 5. 函数拆分原则

- 一个函数尽量聚焦一个明确职责。
- 用参数表达依赖，避免隐式读取全局状态。
- 对非法输入明确选择返回错误结果或抛出异常。
- 避免过长函数、重复代码和含义模糊的变量名。
- 对关键边界条件编写测试。

## 练习

1. 编写一个验证邮箱格式的函数，并说明格式验证的局限。
2. 编写函数计算数组平均值，处理空数组和非法元素。
3. 编写一个将摄氏温度转换为华氏温度的函数。
4. 为除法函数添加除数为零的错误处理。
5. 将一段重复出现的逻辑提取为独立函数。

# 02｜变量、类型与常量

## 学习目标

理解变量命名、常见数据类型、类型转换和常量，并能避免隐式转换导致的业务错误。

## 1. 变量基础

```php
<?php
declare(strict_types=1);

$userName = 'Kai';
$age = 28;
$isActive = true;
$score = 92.5;
$nickname = null;

echo $userName, PHP_EOL;
var_dump($age, $isActive, $score, $nickname);
```

PHP 变量以 `$` 开头。变量名区分大小写，名称应表达业务含义。赋值使用 `=`，它不是数学意义上的相等判断。

## 2. 常见类型

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| bool | `true` | 布尔值 |
| int | `42` | 整数 |
| float | `3.14` | 浮点数，不能直接用于要求绝对精确的金额运算 |
| string | `'PHP'` | 字符串 |
| array | `['php', 'sql']` | 数组 |
| null | `null` | 表示没有值 |
| object | `new stdClass()` | 对象 |

可使用 `get_debug_type($value)` 查看值的类型，使用 `var_dump()` 检查类型和值。

## 3. 比较与类型转换

```php
<?php
var_dump(5 == '5');  // true：宽松比较
var_dump(5 === '5'); // false：值相同但类型不同

$rawAge = '18';
$age = filter_var($rawAge, FILTER_VALIDATE_INT);

if ($age === false || $age < 0) {
    echo '年龄格式无效';
} else {
    echo "年龄：{$age}";
}
```

处理外部输入时，不要仅依赖自动类型转换。应明确验证格式、范围与业务规则。注意 `filter_var()` 的结果可能是 `false`，应使用严格比较识别失败。

## 4. 常量

```php
<?php
const APP_NAME = 'PHP Learning';
define('APP_VERSION', '1.0.0');

echo APP_NAME, ' ', APP_VERSION;
```

常量定义后不能重新赋值。命名风格可以采用大写字母和下划线，便于识别。

## 5. 类型声明

```php
<?php
declare(strict_types=1);

function calculateTotal(int $quantity, float $unitPrice): float
{
    if ($quantity < 0 || $unitPrice < 0) {
        throw new InvalidArgumentException('数量和单价不能为负数');
    }

    return $quantity * $unitPrice;
}

echo calculateTotal(3, 12.5);
```

`strict_types=1` 会影响标量类型声明的调用行为，但它不是完整的输入验证系统，也不会自动验证业务范围。

## 常见陷阱

- 用 `==` 判断身份或枚举值，可能产生意外的类型转换。
- 把字符串 `"0"` 当成空字符串处理。
- 假设用户提交的数据天然就是整数。
- 用二进制浮点数直接进行高精度金额计算。
- 只检查类型、不检查取值范围和业务规则。

## 练习

1. 创建包含姓名、年龄、是否启用的变量，并输出类型。
2. 编写函数，验证输入是否为 0～150 的整数。
3. 比较 `0`、`"0"`、`false`、`null` 的宽松比较和严格比较结果。
4. 编写一个带参数和返回类型的简单计算函数。

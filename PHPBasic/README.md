## 运行示例

在仓库根目录执行：

```bash
php -v
php -l PHPBasic/PHP01/print.php
php PHPBasic/PHP01/print.php
```

网页示例可以使用 PHP 内置开发服务器。本地进入对应目录后执行：

```bash
php -S 127.0.0.1:8000
```

再访问对应文件路径。内置服务器只用于本地学习和调试，不用于生产环境。

## 学习闭环

每一章都做四件事：

- 阅读概念，能用自己的话解释“为什么”。
- 运行示例，观察输出。
- 修改输入，测试空值、边界值和非法值。
- 完成练习，并在提交信息中说明本次学到了什么。

## 基础代码规范

- 新示例优先使用 PHP 8.x，并注明需要的最低版本。
- 文件使用 UTF-8 编码；PHP 文件优先使用统一的缩进和命名风格。
- 面向网页的输出明确区分 HTML 与纯文本。
- 不把用户输入直接拼接到 SQL，也不把未经转义的数据直接输出到 HTML。
- `phpinfo()` 会暴露大量环境信息，只能在本地临时调试，公开服务器上不要保留。
